# Changelog 约定

## 目的
记录每次发版 / 重大改动，作为项目的「事故回溯」与「版本时间线」。AGENTS.md 不变量要求：改完即写，不延后。

## 文件结构
- 顶层 `CHANGELOG.md`：版本总览（时间线表 + 事故级变更表）。
- 每日 `docs/changelog/YYYY-MM-DD.md`：当天所有改动，按版本号/时间排序。

## 单条格式
```markdown
### <版本号或时间戳> · <一句话主题>

- 改动：<做了什么>
- 影响：<影响哪些模块/用户>
- 类型：常规 / 事故级 🔴
- 关联文档：<同步更新的 docs/NN-*.md>
- 备注：<踩坑、回滚、待跟进>
```

## 约定
- 版本号建议带日期前缀（如 `20260923a`），同日多次发版用 a/b/c 递增。
- 事故级变更（白屏/数据错/安全）单独标 🔴，并在顶层 `CHANGELOG.md` 的列里汇总。
- 文档同步是强制的：每条 changelog 必须填「关联文档」。
- 倒补旧 changelog 时，按版本号/记忆倒推，标 `（补记）`。
